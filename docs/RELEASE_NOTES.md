# v0.3.0 - Initial public experimental release

This is the first public release; v0.1 and v0.2 were local development milestones.

- Adds iterative L1/L2 annotation with raw-count compartment rebuilding, optional Harmony and independent external-reference evidence.
- Applies reassignment synchronously, preserves original labels, clears stale subtypes and records exact stability, tolerance, cycle and iteration-cap outcomes.
- Keeps conflicting or unmeasurable evidence unresolved; supports sample-isolated imaging analysis and explicit Visium domain semantics.
- Produces per-round evidence tables, transitions, marker dotplots, reports, h5ad results, JSONL traces and checked notebook replay.
- Includes deterministic synthetic examples with independent reference/query data, bounded agent tools and English method skills.
- Retains scRNA preprocessing, scANVI/TACCO initial annotation and the separately labeled Python SPLIT core.

Real ISD validation is pending. Synthetic correction results are not real-world accuracy estimates. Native R SPLIT parity, trajectory inference, SPATA2, MCP and a web UI are outside this release.

No API key is needed for deterministic workflows. Never commit API keys or private datasets. This public snapshot excludes local outputs, private source templates, environments and non-English documentation.
